# =============================================================

# Usage  : ./scripts/kconfig/merge_config.sh -m .config my-add.txt

# 实测目标硬件（本文件按此硬件裁剪/调优）:
#   SoC      : RK3588  4x Cortex-A76 @2.4GHz + 4x Cortex-A55 @1.8GHz (ARMv8.2)
#   RAM      : 16 GB
#   GPU      : Mali-G610 (Panthor)
#   VPU      : RKVDEC2 解码 + VEPU580 编码 (out-of-tree patch)
#   存储     : eMMC 233GB (HS400/CQE) + M.2 (NVMe 或 JMB582 PCIe→SATA)
#   网络     : 2x RTL8125 2.5GbE (PCIe) + RTL8852BE WiFi6 (PCIe) + Realtek BT (USB)
#   USB      : GL3523 USB3 Hub
#   音频     : ES8328 + HDMI
#   散热     : PWM 风扇 (见 overlay/rk3588-pwm-fan.dtsi)
#
# 注意: merge_config 对同一符号「后出现的行覆盖先出现的行」。
#       文件末尾的 [16] 本机硬件锁定 因此拥有最高优先级。
# =============================================================

# [3.2] ARM64 针对 Cortex-A76 / A55 (ARMv8.2) 的裁剪
# -------------------------------------------------------------
# 以下扩展 RK3588 的 CPU 全部不具备，编译进来只会白白增大内核 text、
# 增加上下文切换分支和 I-cache 压力，关掉没有任何安全或功能损失：
#
#   PTR_AUTH_KERNEL : 需 ARMv8.3 FEAT_PAuth。开启时 GCC 会给每个非叶函数
#                     插入 paciasp/autiasp，在本 CPU 上只是两条 NOP。
#   BTI_KERNEL      : 需 ARMv8.5 FEAT_BTI，同理只会插入 landing pad。
#   MTE             : 需 ARMv8.5 内存标记，本 CPU 无。
#   SVE / SME       : 本 CPU 无向量扩展，关掉可精简 FPSIMD 上下文切换路径。
CONFIG_ARM64_PTR_AUTH_KERNEL=n
CONFIG_ARM64_BTI_KERNEL=n
CONFIG_ARM64_MTE=n
CONFIG_ARM64_SVE=n
CONFIG_ARM64_SME=n

# 48-bit VA (256TB) 对 16GB 内存绰绰有余。
# defconfig 的 52-bit VA 需要 ARMv8.7 LPA2，本 CPU 不支持，
# 内核只能在运行时把第 5 级页表折叠掉——改成 48 位可直接省掉这层间接。
CONFIG_ARM64_VA_BITS_52=n
CONFIG_ARM64_VA_BITS_48=y

# ※ Spectre-BHB / KPTI 缓解措施保持开启（A76 受影响）。
